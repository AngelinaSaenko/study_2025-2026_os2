# Контрольные вопросы  

1. **Какая команда позволяет вам искать пакет rpm, содержащий файл useradd?**  
   Для этого можно использовать несколько команд:  
   - `rpm -qf $(which useradd)` — если файл уже установлен в системе;  
   - `rpm -q --whatprovides /usr/sbin/useradd` — поиск по конкретному пути;  
   - `dnf provides /usr/sbin/useradd` — поиск пакета, содержащего файл, через dnf (включая не установленные).  

2. **Какие команды вам нужно использовать, чтобы показать имя группы dnf, которая содержит инструменты безопасности и показывает, что находится в этой группе?**  
   - `dnf group list | grep -i security` — поиск группы, связанной с безопасностью;  
   - `dnf group info "Security Tools"` — показать подробности о группе (если группа называется "Security Tools").  

3. **Какая команда позволяет вам установить rpm, который вы загрузили из Интернета и который не находится в репозиториях?**  
   - `rpm -ivh имя_пакета.rpm` — установка локального rpm-файла;  
   - `dnf install ./имя_пакета.rpm` — установка через dnf с указанием локального пути.  

4. **Вы хотите убедиться, что пакет rpm, который вы загрузили, не содержит никакого опасного кода сценария. Какая команда позволяет это сделать?**  
   - `rpm -qp --scripts имя_пакета.rpm` — проверка пред- и пост-скриптов в установленном пакете;  
   - `rpm -q --scripts имя_пакета` — проверка скриптов уже установленного пакета.  

5. **Какая команда показывает всю документацию в rpm?**  
   - `rpm -qd имя_пакета` — вывод списка документации установленного пакета;  
   - `rpm -qpd имя_пакета.rpm` — вывод документации из локального rpm-файла.  

6. **Какая команда показывает, какому пакету rpm принадлежит файл?**  
   - `rpm -qf /путь/к/файлу` — определение пакета по установленному файлу;  
   - `dnf whatprovides /путь/к/файлу` — аналог через dnf.  

# Заключение  

В ходе выполнения лабораторной работы №4 я приобрела практические навыки работы с репозиториями и менеджерами пакетов в операционной системе Linux.  

Были выполнены следующие действия:  

- изучение структуры репозиториев и конфигурационных файлов dnf;  

- освоение основных команд менеджера пакетов dnf для поиска, установки, обновления и удаления программного обеспечения;  

- работа с группами пакетов, включая установку и удаление группы "RPM Development Tools";  

- изучение истории транзакций dnf и освоение операций отката изменений;  

- практическая работа с пакетами rpm: установка, удаление, получение информации о пакетах;

В процессе работы я закрепила понимание механизмов управления пакетами в Linux, научилась эффективно использовать менеджер пакетов dnf для решения административных задач, а также освоила работу с rpm-пакетами на низком уровне. Полученный опыт показал важность корректного управления программным обеспечением в системе и продемонстрировал преимущества использования репозиториев для обеспечения безопасности и стабильности рабочей среды.
