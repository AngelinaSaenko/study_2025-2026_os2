# Цели и задачи работы

## Цель лабораторной работы

Получить навыки управления системными службами операционной системы посредством systemd.  

## Задачи лабораторной работы

- Выполнить основные операции по запуску (останову), определению статуса, добавлению (удалению) в автозапуск и пр. службы Very Secure FTP;  
- Продемонстрировать навыки по разрешению конфликтов юнитов для служб firewalld и iptables (раздел 5.4.2);  
- Продемонстрировать навыки работы с изолированными целями.

# Выводы по проделанной работе

## Вывод

В ходе лабораторной работы были освоены:  

- управление системными службами через systemd и утилиту systemctl;  
- работа с различными типами юнитов: service, target, socket и другими;  
- основные операции со службами: запуск, остановка, перезагрузка, проверка статуса;  
- управление автозапуском служб при загрузке системы;  
- анализ зависимостей между юнитами и разрешение конфликтов;  
- работа с изолируемыми целями и переключение между ними;  
- настройка цели по умолчанию для системы;  
- использование механизма маскировки для блокировки служб.
