# Контрольные вопросы  

1. **Что такое юнит (unit)? Приведите примеры.**  
   Юнит (unit) в systemd - это базовый объект, который systemd может управлять. Это может быть служба, точка монтирования, устройство, сокет и т.д.
   Примеры:
   - Сервисные юниты: sshd.service, nginx.service;  
   - Сокетные юниты: sshd.socket;  
   - Целевые юниты: multi-user.target, graphical.target;  
   - Юниты монтирования: home.mount;  

2. **Какая команда позволяет вам убедиться, что цель больше не входит в список автоматического запуска при загрузке системы?**  
   - `systemctl disable имя_цели.target`.  
   
3. **Какую команду вы должны использовать для отображения всех сервисных юнитов, которые в настоящее время загружены?**  
   - `systemctl list-units --type=service`.  

4. **Как создать потребность (wants) в сервисе?**  
   - `systemctl add-wants имя_цели.target имя_сервиса.service`;  
   Или созданием символической ссылки в директории wants:  
   - `ln -s /usr/lib/systemd/system/имя_сервиса.service /etc/systemd/system/имя_цели.target.wants/`.  
   
5. **Как переключить текущее состояние на цель восстановления (rescue target)?**  
   - `systemctl rescue`;  
   Или через перезагрузку с параметром:  
   - `systemctl default rescue.target`.  
   
6. **Поясните причину получения сообщения о том, что цель не может быть изолирована**  
     Это происходит когда:
   - Цель имеет конфликтующие зависимости с другими юнитами;  
   - Недостаточно юнитов для изоляции целевого состояния;  
   - Цель является обязательной для работы системы;  
   - Отсутствуют необходимые зависимости для изоляции.  
   
7. **Вы хотите отключить службу systemd, но, прежде чем сделать это, вы хотите узнать, какие другие юниты зависят от этой службы. Какую команду вы бы использовали?**  
   - `systemctl list-dependencies имя_сервиса.service --reverse`.  

# Заключение  

В ходе выполнения лабораторной работы №5 я приобрела практические навыки управления системными службами операционной системы Linux посредством systemd.  

Были выполнены следующие действия:  

- изучение архитектуры systemd и типов юнитов (service, socket, target, mount и др.);  

- освоение основных команд управления юнитами: запуск, остановка, перезагрузка, проверка статуса;  

- практическая работа с сервисом Very Secure FTP (vsftpd): установка, управление состоянием, настройка автозапуска;  

- анализ зависимостей между юнитами с помощью команд list-dependencies;  

- разрешение конфликтов между службами firewalld и iptables;  

- освоение механизма маскировки юнитов для предотвращения их случайного запуска;  

- работа с изолируемыми целями (targets): изучение доступных целей, переключение между ними;  

- настройка цели по умолчанию для системы (multi-user.target и graphical.target);  

- анализ структуры каталогов systemd и символических ссылок в директориях wants.  

В процессе работы я закрепила понимание механизмов управления системными службами через systemd, научилась эффективно использовать systemctl для администрирования сервисов, а также освоила методы разрешения конфликтов между службами. Полученный опыт показал важность корректного управления зависимостями служб и продемонстрировал преимущества использования целей (targets) для организации различных состояний системы.
