# Выводы по проделанной работе

## Вывод

В ходе лабораторной работы были освоены:  

- управление процессами операционной системы Linux;  
- мониторинг процессов с помощью команд ps, top, htop;  
- работа с заданиями оболочки (jobs) и их состояниями;  
- основные операции с процессами: запуск, остановка, приостановка, возобновление;  
- управление приоритетами процессов с помощью команд nice и renice;  
- запуск процессов в фоновом режиме с сохранением после завершения сессии (nohup);  
- анализ иерархии процессов и отношений "родитель-потомок";  
- завершение процессов различными способами: по PID, имени, группе;  
- работа с сигналами управления процессами (SIGKILL, SIGHUP и др.);  
- эффективное распределение системных ресурсов через управление приоритетами.
