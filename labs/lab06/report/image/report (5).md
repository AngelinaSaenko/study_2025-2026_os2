# Контрольные вопросы  

1. **Какая команда даёт обзор всех текущих заданий оболочки?**  
   - `jobs`  
![jobs](image/17.jpg){ #fig:017 width=80% }  
   
2. **Как остановить текущее задание оболочки, чтобы продолжить его выполнение в фоновом режиме?**  
  - Нажать `Ctrl+Z` для остановки задания, затем выполнить `bg` для продолжения в фоновом режиме.  
![Остановка задания](image/18.jpg){ #fig:018 width=80% }  
   
3. **Какую комбинацию клавиш можно использовать для отмены текущего задания оболочки?**  
   - `Ctrl+C`.  
![Отмена текущего задания](image/19.jpg){ #fig:019 width=80% }  
   
4. **Необходимо отменить одно из начатых заданий. Доступ к оболочке, в которой в данный момент работает пользователь, невозможен. Что можно сделать, чтобы отменить задание?**  
   - Использовать команду `kill` с PID процесса из другого терминала;  
   - Или использовать команду `killall` с именем процесса  
![kill](image/20.jpg){ #fig:020 width=80% }  
![killall](image/21.jpg){ #fig:021 width=80% }  
   
5. **Какая команда используется для отображения отношений между родительскими и дочерними процессами?**  
   - `ps fax` или `pstree`
![Отображение тношений](image/22.jpg){ #fig:022 width=80% }  
   
6. **Какая команда позволит изменить приоритет процесса с идентификатором 1234 на более высокий?**  
   - `renice -n -5 1234` (только для суперпользователя)  
![Изменение приоритета](image/23.jpg){ #fig:023 width=80% }  
   
7. **В системе в настоящее время запущено 20 процессов dd. Как проще всего остановить их все сразу?**  
   - `killall dd` или `pkill dd`.  
![Остановка всех сразу процессов](image/24.jpg){ #fig:024 width=80% }  
   
8. **Какая команда позволяет остановить команду с именем mycommand?**  
   - `pkill mycommand` или `killall mycommand`  
![Изменение приоритетов](image/25.jpg){ #fig:025 width=80% }  
   
9. **Какая команда используется в top, чтобы убить процесс?**  
   - Нажать клавишу `k`, затем ввести PID процесса  
   
10. **Как запустить команду с достаточно высоким приоритетом, не рискуя, что не хватит ресурсов для других процессов?**  
   - Использовать команду `nice` с положительным значением: `nice -n 10 команда`;  
   - Или запустить с пониженным приоритетом: `nice -n 19 команда`.  
![Высокий приоритет](image/26.jpg){ #fig:026 width=80% }  

# Заключение  

В ходе выполнения лабораторной работы №6 я приобрела практические навыки управления  процессами операционной системы Linux.  

Были выполнены следующие действия:  

- изучение основных команд для работы с процессами: ps, top, htop, pstree;  

- освоение управления заданиями (jobs) в оболочке: запуск в фоновом и foreground режимах;  

- практическая работа с командами fg, bg, jobs для контроля выполнения заданий;  

- изменение приоритетов процессов с помощью команд nice и renice;  

- освоение механизма запуска процессов с сохранением выполнения после завершения сессии (nohup);  

- анализ состояний процессов (Running, Sleeping, Stopped, Zombie) и их характеристик;  

- практическое применение сигналов для управления процессами (SIGKILL, SIGHUP);  

- завершение процессов различными способами: через kill, killall, по идентификаторам заданий;  

- анализ иерархии процессов и отношений "родитель-потомок";  

- разрешение конфликтов ресурсов через управление приоритетами выполнения.

В процессе работы я закрепила понимание механизмов управления процессами в Linux, научилась эффективно использовать команды ps, top, jobs для мониторинга системной активности, а также освоила методы управления приоритетами выполнения процессов. Полученный опыт показал важность корректного управления системными ресурсами и продемонстрировал преимущества фонового выполнения длительных операций с сохранением стабильности работы системы.
