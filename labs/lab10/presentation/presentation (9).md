# Выводы по проделанной работе

## Вывод

В ходе лабораторной работы были освоены:  

- принципы работы с модулями ядра операционной системы Linux;  
- управление модулями ядра с помощью утилит modprobe, lsmod и modinfo;  
- загрузка и выгрузка модулей ядра из командной строки;  
- анализ параметров модулей ядра и их конфигурация;  
- работа с зависимостями модулей ядра;  
- определение связанных модулей для системных устройств;  
- обновление ядра операционной системы с использованием DNF;  
- проверка версии ядра и анализ информации о системе;  
- диагностика проблем при выгрузке используемых модулей;  
- настройка функциональности системы через управление модулями ядра.
