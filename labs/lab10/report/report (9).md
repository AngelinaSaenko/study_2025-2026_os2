# Контрольные вопросы  

1. **Какая команда показывает текущую версию ядра, которая используется на вашей системе?**  
 - - `uname -r`.  
   
2. **Как можно посмотреть более подробную информацию о текущей версии ядра операционной системы?**  
 - `hostnamectl`.  
  
3. **Какая команда показывает список загруженных модулей ядра?**  
 - `lsmod`.  

4. **Какая команда позволяет вам определять параметры модуля ядра?**  
 - `modinfo`.  

5. **Как выгрузить модуль ядра?**  
  -  `modprobe -r <имя_модуля>`.  
   
6. **Что вы можете сделать, если получите сообщение об ошибке при попытке выгрузить модуль ядра?**  
   -  Если модуль используется системой, его нельзя выгрузить. Необходимо сначала остановить службы или процессы, использующие этот модуль, и повторить попытку выгрузки.  
   
7. **Как определить, какие параметры модуля ядра поддерживаются?**  
   - С помощью команды `modinfo <имя_модуля>` можно просмотреть список всех параметров, которые поддерживаются модулем.  
   
8. **Как установить новую версию ядра?**  
   - Выполнить команды:
     ```
     dnf update kernel
     dnf update
     dnf upgrade --refresh
     ```
     После этого необходимо перезагрузить систему и выбрать новое ядро при загрузке.  

# Заключение  

В ходе выполнения лабораторной работы №10 я приобрела практические навыки работы с модулями ядра операционной системы Linux.

Были выполнены следующие действия:

- изучение архитектуры ядра Linux и принципов работы модулей ядра как программного кода, расширяющего функциональные возможности системы;  

- освоение утилит управления модулями ядра: `modprobe` для загрузки и выгрузки модулей, `modinfo` для получения информации о модулях, `lsmod` для просмотра загруженных модулей;  

- практическая работа с модулями ядра из командной строки: загрузка и выгрузка модулей, анализ зависимостей;  

- изучение параметров модулей ядра и освоение методики загрузки модулей с различными параметрами;  

- анализ списка устройств системы и связанных с ними модулей ядра с помощью утилиты `lspci -k`;

- освоение процедуры проверки текущей версии ядра с помощью команд `uname -r` и `hostnamectl`.  

В процессе работы я закрепила понимание модульной архитектуры ядра Linux и научилась управлять модулями ядра для расширения функциональности операционной системы. Полученные навыки позволяют эффективно администрировать систему, обновлять ядро и настраивать его параметры, что является важным аспектом в работе системного администратора операционных систем Linux.
