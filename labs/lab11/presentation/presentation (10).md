# Цели и задачи работы

## Цель лабораторной работы

Получить навыки работы с загрузчиком системы GRUB2.  

## Задачи лабораторной работы
 
-  Продемонстрировать навыки по изменению параметров GRUB и записи изменений
в файл конфигурации.  
-  Продемонстрировать навыки  устранения неполадок при работе с GRUB.  
-  Продемонстрировать навыки работы с GRUB без использования root.

# Выводы по проделанной работе

## Вывод

В ходе лабораторной работы были освоены:

- принципы работы с загрузчиком системы GRUB2;  
- модификация параметров загрузки через файл /etc/default/grub;  
- генерация основной конфигурации GRUB2 с помощью grub2-mkconfig;  
- методы устранения неполадок при загрузке системы;  
- использование аварийных режимов rescue.target и emergency.target;  
- процедура сброса пароля root через параметр rd.break;  
- монтирование корневой файловой системы в режиме чтения-записи;  
- работа с chroot-окружением для восстановления доступа к системе;  
- восстановление контекстов SELinux после сброса пароля;  
- настройка параметров загрузки ядра через командную строку GRUB.
