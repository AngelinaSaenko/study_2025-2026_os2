## Устранения неполадок

После перезагрузки системы я, только появилось меню GRUB, выберала строку с текущей версией ядра в меню и нажала e для редактирования. После прокрутила вниз до строки, начинающейся с linux ($root)/vmlinuz-. Эта строка загружает ядро системы. В конце этой строки ввела systemd.unit=rescue.target
и удалила опции rhgb и quit. Затем нажала Ctrl + x для продолжения процесса загрузки. После этого ввела пароль пользователя root при появлении запроса. Это можно увидеть ниже.

# Контрольные вопросы  

1. **Какой файл конфигурации следует изменить для применения общих изменений в GRUB2?**  
 - `/etc/default/grub`.  
   
2. **Как называется конфигурационный файл GRUB2, в котором вы применяете изменения для GRUB2 ?**  
 - `/boot/grub2/grub.cfg`.  
  
3. **После внесения изменений в конфигурацию GRUB2, какую команду вы должны выполнить, чтобы изменения сохранились и воспринялись при загрузке системы?**  
 - `grub2-mkconfig -o /boot/grub2/grub.cfg`.  

# Заключение  

В ходе выполнения лабораторной работы №11 я приобрела практические навыки работы с загрузчиком системы GRUB2.

Были выполнены следующие действия:

- изучение архитектуры и принципов работы загрузчика GRUB2 в операционных системах Linux;  
- освоение модификации параметров загрузки через конфигурационный файл `/etc/default/grub`;  
- практическое применение команды `grub2-mkconfig` для генерации основной конфигурации GRUB2;  
- освоение методов устранения неполадок при загрузке системы с использованием параметров `rd.break`, `systemd.unit=rescue.target` и `systemd.unit=emergency.target`;    
- практика сброса пароля пользователя root через аварийный режим загрузки;
- изучение процедуры монтирования корневой файловой системы в режиме чтения-записи и работы с chroot-окружением;  
- освоение восстановления контекстов SELinux после сброса пароля с помощью команд `load_policy` и `chcon`.  

В процессе работы я закрепила понимание процесса загрузки операционной системы и научилась управлять параметрами загрузчика GRUB2 для решения различных административных задач. Полученные навыки позволяют эффективно восстанавливать доступ к системе, настраивать параметры загрузки и устранять неполадки, возникающие на этапе запуска операционной системы, что является важным аспектом в работе системного администратора.
